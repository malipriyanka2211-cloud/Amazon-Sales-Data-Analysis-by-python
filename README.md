# Amazon Sales Data Analysis
# Overview

This project focuses on analyzing Amazon sales data using Python to extract meaningful business insights and identify sales trends. The project includes data cleaning, exploratory data analysis (EDA), and visualization to better understand customer behavior, product performance, and overall business growth.

# Tools & Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

# Project Objectives
Analyze Amazon sales performance
Identify top-performing products and categories
Understand customer purchasing behavior
Perform data cleaning and preprocessing
Generate business insights using visualizations

# Features
Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Sales Trend Analysis
Product Category Analysis
Revenue & Profit Insights
Data Visualization using charts and graphs
